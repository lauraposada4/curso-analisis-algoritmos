# Semana 02: Configuración del entorno de trabajo

En esta semana se configuró el entorno virtual del curso, se aplicaron convenciones PEP 8 y type hints.

## Comandos del Entorno Virtual
- **Creación del entorno (desde la carpeta raíz):** `python -m venv venv`
- **Activación en Git Bash:** `source venv/Scripts/activate`
